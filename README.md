# Шпаргалки к экзаменам

Справочник к универскому ивенту в GTA 5 RP. Vite + Vue 3 + TypeScript, архитектура по
Feature-Sliced Design, деплой на GitHub Pages через Actions.

**Главная** — 10 предметов, которые открываются по одному в день с 1 сентября. Даты считаются
в браузере, вручную ничего разблокировать не надо.

**Химия** — верстак алхимика на 715 рецептов:

- **Комбинировать** — выбираешь элемент, сетка сужается до тех, с чем он реально смешивается;
  на плитке подписан результат.
- **Как сделать** — пошаговая цепочка с нуля до нужного элемента плюс «где ещё используется».
- **Список** — все рецепты с чекбоксами, прогресс хранится в `localStorage`.

Цифра в углу плитки — сколько синтезов отделяет элемент от четырёх базовых. Поиск фокусируется
клавишей `/`.

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173/university/
npm run build      # проверка типов + сборка в dist/
npm run preview    # посмотреть собранное
npm run typecheck  # только типы
```

## Архитектура

Feature-Sliced Design. Слои сверху вниз, импорт разрешён **только вниз**: страница может взять
виджет, виджет — фичу, фича — сущность, все — `shared`. Обратно и вбок (виджет из виджета,
сущность из сущности) — нельзя.

```
src/
├─ app/         инициализация: роутер, глобальные стили, токены темы
├─ pages/       subjects (главная), chemistry (верстак)
├─ widgets/     subject-grid, combiner, recipe-path, recipe-book, element-detail
├─ features/    combine-elements, element-search, track-progress, toggle-theme
├─ entities/    element (иконки, плитки), recipe (граф синтезов), subject (расписание)
└─ shared/      ui-кит, утилиты, типы, реактивный localStorage
```

Каждый слайс отдаёт наружу только то, что перечислено в его `index.ts` — внутрь чужого слайса
импортов быть не должно.

Запрет на импорт вбок решён в двух местах:

- `combiner` и `recipe-path` не тянут `element-detail` напрямую, а получают карточку элемента
  слотом от страницы `chemistry`;
- `entities/recipe` рисует ингредиенты компонентом из `entities/element` — через официальную
  витрину cross-import `src/entities/element/@x/recipe.ts`. Это единственный разрешённый
  проход между сущностями, и он объявлен явно.

Состояние — на композаблах Vue (`useCombiner`, `useProgress`, `useElementSearch`), без Pinia:
сторов мало и они простые.

### Где что менять

**Названия предметов** — `src/entities/subject/model/subjects.ts`. Порядок в массиве `SUBJECTS`
задаёт день открытия: первый элемент открывается 1 сентября, второй 2-го и так далее. Поле
`route` — имя маршрута, который откроется по клику; без него карточка показывает
«гайда пока нет». Дату старта задаёт `EVENT_START` там же (месяцы в JS считаются с нуля,
сентябрь — `8`).

**Рецепты** — `src/entities/recipe/api/recipes.txt`. Первая значимая строка — базовые элементы
через `|`, дальше по строке на рецепт: `Элемент+Элемент=Результат`. Строки с `#` — комментарии.
Номера проставляются при разборе, так что вставлять можно куда угодно.

**Эмодзи элементов** — `src/entities/element/api/emoji.txt`, пары `Название=эмодзи`.
Для элемента без строки подставляется 🔹.

**Свои картинки вместо эмодзи** — положи PNG в `public/icons` (имя файла = название элемента)
и поставь `USE_IMAGES = true` в `src/entities/element/model/icon.ts`. Подробности —
`public/icons/README.md`.

**Новый предмет с собственным гайдом** — заводишь `src/pages/<предмет>`, добавляешь маршрут
в `src/app/router/index.ts` и прописываешь его имя в поле `route` нужного предмета.

## Деплой на GitHub Pages

Workflow `.github/workflows/deploy.yml` собирает проект на каждый пуш в `main` и публикует `dist`.

Один раз включи это в репозитории: **Settings → Pages → Source: GitHub Actions**
(не «Deploy from a branch» — сборка идёт в Actions).

Сайт поднимется на `https://uptostar.github.io/university/`.

Две вещи, которые ломают деплой чаще всего:

- **`base` в `vite.config.ts`** должен совпадать с именем репозитория (`/university/`).
  Переименуешь репозиторий — поправь и здесь, иначе стили и скрипты уйдут в 404.
- **Приватный репозиторий.** Pages работает с приватными репозиториями только на тарифах
  Pro, Team и Enterprise. На бесплатном репозиторий должен быть публичным.

Роутинг — хешевый (`/university/#/chem`) намеренно: при history-режиме GitHub Pages отдаёт 404
на прямой заход по вложенному пути, и это приходится лечить копией `index.html` в `404.html`.

## Расхождения с исходным списком

В гайде несколько разных предметов назывались одинаково — такие рецепты затирали друг друга,
поэтому они переименованы:

| В гайде | Здесь |
| --- | --- |
| Нефть (Подсолнух + Давление) | Растительное масло |
| Нефть (Молоко + Давление) | Сливочное масло |
| Сок (Дерево + Клинок) | Древесный сок |
| Пиво (Пиво + Пшеница) | Светлое пиво |
| Котёл (Керамика + Металл) | Котелок |
| Икра (Икра + Соль) | Чёрная икра |
| Труба (Табак + Инструмент) | Курительная трубка |

Если в игре названия другие — поправь их в `recipes.txt` и `emoji.txt`.
