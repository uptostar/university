# Шпаргалки к экзаменам

Справочник к универскому ивенту в GTA 5 RP. Один HTML-файл, без сборки и зависимостей — открывается двойным кликом и одинаково работает на GitHub Pages.

**Главная** — 10 предметов, которые открываются по одному в день с 1 сентября. Даты считаются в браузере, вручную ничего разблокировать не надо.

**Химия** — верстак алхимика на 715 рецептов:

- **Комбинировать** — выбираешь элемент, список сразу сужается до тех, с чем он реально смешивается; на плитке подписан результат.
- **Как сделать** — пошаговая цепочка с нуля до нужного элемента (берётся кратчайший путь) плюс «где ещё используется».
- **Список** — все рецепты с чекбоксами, прогресс хранится в `localStorage`.

Цифра в углу плитки — сколько шагов от четырёх базовых элементов. Поиск фокусируется клавишей `/`.

## Публикация на GitHub Pages

1. Создай репозиторий на GitHub (публичный).
2. Залей в него содержимое этой папки — `index.html` должен лежать в корне.
3. Settings → Pages → Source: `Deploy from a branch`, ветка `main`, папка `/ (root)`.
4. Через минуту сайт поднимется на `https://<логин>.github.io/<репозиторий>/`.

Если ставишь через командную строку:

```bash
git init
git add .
git commit -m "Шпаргалки к экзаменам"
git branch -M main
git remote add origin https://github.com/<логин>/<репозиторий>.git
git push -u origin main
```

Дальше пункт 3 из списка выше. Каждый следующий `git push` обновляет сайт за пару минут.

Файл `.nojekyll` в корне нужен, чтобы GitHub Pages отдавал всё как есть и не пытался прогонять содержимое через Jekyll.

## Свои картинки вместо эмодзи

По умолчанию у элементов эмодзи. Чтобы поставить иконки из игры:

1. Положи PNG в папку `icons`, назвав файлы точно как элементы: `Лава.png`, `Древесина.png`, `Пряничный человечек.png`.
2. В `index.html` найди `const USE_IMG=false;` и поменяй на `true`.

Для элементов без файла останется эмодзи, так что можно добавлять иконки постепенно.

## Что править дальше

Всё лежит в `index.html`, отдельных файлов нет.

**Названия предметов** — массив `SUBJ` в теге `<script>`. Порядок в массиве = день открытия: первый элемент открывается 1 сентября, второй 2-го и так далее.

```js
const SUBJ=[
  {n:"Педагогика",  e:"📚"},
  {n:"Информатика", e:"💻"},
  {n:"Химия",       e:"⚗️", go:"chem"},
  ...
];
```

Поле `go` — экран, который открывается по клику. Пока такой экран один (`chem`); у предметов без `go` карточка показывает «гайда пока нет».

**Год и месяц ивента** — константы `YEAR` и `MON` рядом с `SUBJ` (`MON` считается с нуля, то есть сентябрь — это `8`).

**Рецепты** — строка `RAW` в начале скрипта, формат `номер Элемент+Элемент=Результат`. Первая строка — четыре базовых элемента через `|`. Номера рецептов проставляются заново при загрузке, так что можно вставлять строки в любое место.

**Эмодзи элементов** — строка `EMO`, пары `Название=эмодзи` через `|`. Для элемента без пары подставляется 🔹.

## Расхождения с исходным списком

В гайде несколько разных предметов назывались одинаково — такие рецепты затирали друг друга, поэтому они переименованы:

| В гайде | Здесь |
| --- | --- |
| Нефть (Подсолнух + Давление) | Растительное масло |
| Нефть (Молоко + Давление) | Сливочное масло |
| Сок (Дерево + Клинок) | Древесный сок |
| Пиво (Пиво + Пшеница) | Светлое пиво |
| Котёл (Керамика + Металл) | Котелок |
| Икра (Икра + Соль) | Чёрная икра |
| Труба (Табак + Инструмент) | Курительная трубка |

Если в игре названия другие — поправь их в `RAW` и `EMO`.
