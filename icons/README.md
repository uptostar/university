# Иконки элементов

Сюда кладутся PNG вместо эмодзи. Имя файла = название элемента ровно так, как оно написано в рецептах:

```
icons/Лава.png
icons/Древесина.png
icons/Пряничный человечек.png
icons/Чёрная икра.png
```

Регистр, пробелы и буква «ё» важны — `Лед.png` не подхватится, нужно `Лёд.png`.

Дальше в `index.html` найди строку

```js
const USE_IMG=false;
```

и поставь `true`.

Размер — 64×64 или больше, квадрат, лучше с прозрачным фоном: на странице иконка рисуется в 30×30 и подгоняется по `object-fit: contain`.

Файлы можно добавлять по одному: у элементов, для которых картинки нет, останется эмодзи.
