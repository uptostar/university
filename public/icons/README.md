# Иконки элементов

Сюда кладутся PNG вместо эмодзи. Имя файла = название элемента ровно так, как оно написано
в `src/entities/recipe/api/recipes.txt`:

```
public/icons/Лава.png
public/icons/Древесина.png
public/icons/Пряничный человечек.png
public/icons/Чёрная икра.png
```

Регистр, пробелы и буква «ё» важны — `Лед.png` не подхватится, нужно `Лёд.png`.

Дальше в `src/entities/element/model/icon.ts` поменяй

```ts
export const USE_IMAGES = false
```

на `true`.

Размер — 64×64 или больше, квадрат, лучше с прозрачным фоном: на странице иконка рисуется
в 30×30 и подгоняется по `object-fit: contain`.

Файлы можно добавлять по одному: у элементов, для которых картинки нет, останется эмодзи.

Всё из `public/` копируется в сборку как есть, без обработки Vite.
